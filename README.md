# Página de Receitas

Projeto introdutório desenvolvido durante os estudos na **Rocketseat**, com o objetivo de praticar os fundamentos de **HTML e CSS** através da construção de uma página de receita.

A interface apresenta uma receita de cupcake de café com chantilly, organizada em informações gerais, ingredientes e modo de preparo.

## 🎯 Objetivo

Praticar os primeiros conceitos de desenvolvimento web e compreender como HTML e CSS trabalham juntos na construção e estilização de uma página.

## 🛠️ Tecnologias

- HTML5
- CSS3
- Google Fonts

## 📚 Conceitos praticados

Durante o desenvolvimento foram trabalhados conceitos como:

- Estrutura básica de um documento HTML
- HTML semântico
- Títulos e parágrafos
- Listas
- Imagens e atributos `alt`
- Seções de conteúdo
- Seletores CSS
- Cores e tipografia
- Margens e espaçamentos
- Bordas e organização visual
- Importação de fontes externas

## 🧩 Estrutura da página

A página é dividida em:

- Apresentação da receita
- Informações de tempo, rendimento e dificuldade
- Lista de ingredientes
- Modo de preparo
- Rodapé

## 📖 Contexto

Este projeto faz parte dos meus estudos em desenvolvimento web na **Rocketseat** e representa uma das etapas iniciais da minha prática com HTML e CSS.

Foi utilizado para compreender como estruturar uma página e aplicar estilos para transformar o conteúdo HTML em uma interface visual.
